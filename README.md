# WT-4: Веб-приложение «Доставка еды»

Лабораторная работа WT-4 — ASP.NET Core MVC приложение для службы доставки еды.

## Функциональность

- 🍕 Каталог блюд с фильтрацией по категориям
- 🏛️ Раздел ресторанов с рейтингами и адресами
- 🚚 Раздел курьеров с фото и статистикой
- ➕ CRUD-операции: создание, просмотр, удаление блюд
- 🎨 Оформление в оливково-кремовой гамме с курсивными шрифтами
- 📱 Адаптивная вёрстка (Bootstrap 5)

## Технологии

- ASP.NET Core 8 MVC
- Razor Views
- Bootstrap 5
- Google Fonts (Playfair Display, Lora)
- Docker
